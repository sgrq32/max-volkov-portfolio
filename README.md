# Max Volkov — Web Development Portfolio

## Overview
Personal portfolio combining three clearly labelled demonstration projects and the real, private NERYO product case study.

## Features
- Four differentiated portfolio cases
- Dedicated NERYO case-study route with safe screenshot placeholders
- Services, process and FAQ sections
- Configurable contacts and live-project links
- Responsive navigation, SEO, Open Graph metadata and favicon

## Stack
- Next.js
- React
- TypeScript
- CSS

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Configuration
Fill `src/config/contact.ts` before publishing. After deploying the three demos, add their public URLs to `src/config/projects.ts`. No contact details are fabricated.

NERYO remains a separate private product. No source code, credentials, private URLs or production architecture are included here.

## Disclaimer
The portfolio includes fictional demonstration projects that do not imply a commercial relationship with a real company. NERYO is clearly identified as a real product in active development.
