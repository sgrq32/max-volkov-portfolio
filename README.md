# Max Volkov — Portfolio

![Screenshot placeholder](./docs/screenshot-placeholder.png)

Personal web-development portfolio combining three clearly labelled demo projects and the real, private NERYO product case study.

## Features
- Four differentiated portfolio cases
- Dedicated NERYO case-study route with safe screenshot placeholders
- Services, process, FAQ and configurable contacts
- Responsive navigation, SEO/Open Graph metadata and favicon

## Stack
Next.js 16 · React 19 · TypeScript · CSS

## Contacts
Fill `src/config/contact.ts` before publishing. No contact details are fabricated.
After deploying the three demos, add their public URLs to `src/config/projects.ts`.

## Local development / build
```bash
npm install
npm run dev
npm run build
npx vercel --prod
```

NERYO remains a separate private product. No source code, credentials, private URLs or production architecture are included here.
